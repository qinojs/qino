# cms.backend.ai.feedback

Beta: not reviewed yet. This module's design, behaviour and structure are provisional and may be reworked.

Backend page for [ai.agent.feedback](../ai.agent.feedback/): what agents report about the system and which
model reported it, by what it is about (a tool's name, or *system* for the whole), to mark done, open again
or remove; beside it the tool calls that failed in the latest messages of all sessions, also those no agent
reported.
