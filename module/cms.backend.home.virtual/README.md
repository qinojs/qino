# cms.backend.home.virtual

This module's design, behaviour and structure are provisional and may be reworked.
Real-world use will show how it is actually used and how it should work.

Backend page for [home.virtual](../home.virtual/), below the home automation page. It lists virtual
entities, applies device templates (a device provider, the device name, a virtual provider) and adds
single virtual entities from a source entity, a stored command and a value schema. Without a virtual
provider it offers to create one. Access is the backend page's CMS node access.
