# cms.cont.slideshow

Add images to the block's files; each becomes a slide of a `u2-carousel`, in file-list order, and
the slides change by themselves. The images fill the slideshow, cropped to its proportions (2:1;
a site sets `aspect-ratio` on `[qcms-mod="cont.slideshow"] > u2-carousel`). No settings, no
module-specific JavaScript.
