# cms.cont.gallery.masonry

Add images to the content block's files. Their order follows the file list.
`u2-masonry` preserves image proportions; clicking opens the original in a grouped
`u2-lightbox`, which uses `u2-carousel` for navigation.

`cms-image2` handles responsive image loading and previews.
Use u2's `--u2-Items-width` and `gap` CSS properties to customize the layout.
The optional `col-width` setting passes a CSS value such as `11em` or `33vw` to u2.
No configuration or module-specific JavaScript is needed.
